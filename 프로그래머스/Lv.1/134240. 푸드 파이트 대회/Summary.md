# 🤖 AI 분석

## 💡 접근 방식

주어진 음식 리스트에서 재료를 역순으로 탐색하고, 각각의 재료 수에 따라 결과 문자열을 생성하는 방식으로 풀이.

## ⏱️ 시간 복잡도

O(N²) — 각 재료 수 `f`에 대해 최대 `f/2`번의 join이 발생하여, 최악의 경우 전체 음식의 합만큼 연산이 수행됨. 일반적으로 O(N²)의 성능.

## 📦 공간 복잡도

O(N) — 결과 문자열 `answer`에 최악의 경우 모든 음식 정보를 저장하므로 전체 입력 크기와 비례하는 공간 사용.

## 🔧 개선 사항

1) join의 사용을 피하고 문자열 덧셈을 사용할 것 — join를 반복적으로 사용하는 것은 비효율적입니다.
2) answer를 리스트에 추가 후 마지막에 join으로 합치는 것이 성능 향상.
3) 불필요한 프린트 문 삭제하여 코드를 간결하게 할 것.

## 🏷️ 태그

array, string, implementation

## ✨ 모범 답안

```python
def solution(food):
    answer = []
    for i, f in enumerate(food[:-1]):  # food 리스트의 마지막 요소 제외
        answer.extend([str(i)] * (f // 2))  # 반으로 나눈 수만큼 i를 추가
    return ''.join(answer) + '0' + ''.join(answer[::-1])
```
