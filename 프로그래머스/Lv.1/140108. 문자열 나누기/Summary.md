# 🤖 AI 분석

## 💡 접근 방식

주어진 문자열을 반복적으로 분석하여 동일한 문자의 개수와 다른 문자의 개수를 세는 구조로, 두 수가 같아졌을 때 분할.

## ⏱️ 시간 복잡도

O(N²) — 외부 루프에서 i를 증가시키는 방법으로 내부 루프를 문자열의 나머지 길이만큼 순회, 최악의 경우 O(N) 반복 재귀가 발생하여 최종적으로 O(N²).

## 📦 공간 복잡도

O(1) — 추가적인 자료구조는 사용하지 않고 변수를 몇 개 사용하는 방식이다.

## 🔧 개선 사항

1) 내부 루프를 슬라이스 대신 인덱스를 통해 제어하여 문자열의 나머지를 반복 접근하는 비용을 절감할 수 있음.
2) 단일 루프로 검사를 수행하여 시간 복잡도를 줄일 수 있다. 추가 계수를 사용해 문자를 카운트하는 로직으로 리팩토링 필요.
3) 코드 가독성을 위해 함수와 변수를 이해하기 쉽게 변경할 수 있음.

## ✨ 모범 답안

```python
def solution(s):
    answer = 0
    i = 0
    while i < len(s):
        first = s[i]
        count = 1
        balance = 0
        for j in range(i + 1, len(s)):
            if s[j] == first:
                count += 1
            else:
                balance += 1
            if count == balance:
                break
        i = j + 1
        answer += 1
    return answer
```
